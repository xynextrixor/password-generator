# 🔐 Random Password Generator

A modern, responsive React password generator application with customizable character options, built with Vite.

## Features

✨ **Key Features:**

- 🎯 Generate random passwords with customizable length (4-50 characters)
- 🔤 **Uppercase Letters** - Include A-Z in your password
- 🔡 **Lowercase Letters** - Include a-z in your password
- 🔢 **Numbers** - Include 0-9 in your password
- 🔣 **Special Characters** - Include !@#$%^&\* and more
- 📋 **Copy to Clipboard** - Click to copy generated password
- ✅ **Visual Feedback** - See when your password is copied
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile

## Installation & Setup

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## How to Use

1. **Adjust Password Length** - Use the slider to set desired length (4-50 characters)
2. **Select Character Types** - Check/uncheck options for:
   - Uppercase letters (A-Z)
   - Lowercase letters (a-z)
   - Numbers (0-9)
   - Special characters (!@#$%^&\*...)
3. **Generate Password** - Click "Generate Password" button
4. **Copy Password** - Click "Copy" button to copy to clipboard
